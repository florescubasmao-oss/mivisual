CAMBIOS PRINCIPALES
===================

1) CARGO DE ACTAS
- Se elimina el ScriptLock global prolongado del proceso.
- Se reservan únicamente las actas seleccionadas.
- Dos usuarios pueden recibir grupos diferentes simultáneamente.
- Se agrega SOLICITUD_ID_CLIENTE para idempotencia y recuperación.
- Si el navegador pierde la respuesta, MI VISUAL verifica el ID antes de repetir.
- El cargo puede reconciliarse si quedó en PENDIENTE_APLICAR.

2) ACTAS: MÁXIMO 40
- Frontend y backend: máximo 40.
- El PDF conserva 2 columnas hasta 20 y usa 4 columnas compactas de 21 a 40.
- No se omiten los números 21 al 40.

3) EQUIPOS AVERIADOS
- Se elimina el ScriptLock global durante PDF/Drive.
- Reserva específica por solicitud.
- El PDF ya no se devuelve como Base64; se usa enlace Drive.
- Escrituras: hasta 105 s antes de cortar.
- Si la respuesta se pierde, se verifica la operación por SOLICITUD_ID_CLIENTE.
- Si un cargo quedó creado pero no aplicado, se reconcilia automáticamente.
- Catálogo, solicitudes y cargos se leen por GET.
- Búsqueda por ID usa TextFinder.
- Ya no se reescriben todos los encabezados en cada lectura.

4) CHECKLIST MESH
- Ya estaba correcto en el proyecto entregado:
  Mesh ZTE = máximo 10
  Mesh Huawei = máximo 10
- V399 conserva esa regla.
